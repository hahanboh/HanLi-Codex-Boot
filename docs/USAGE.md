# 安装、使用与恢复

## 安装

先在官方Codex中确认登录和正常聊天。安装器只支持当前检测到的OpenAI.Codex MSIX，普通权限即可。源码路径和安装路径不同；安装默认在当前用户LOCALAPPDATA/HanLiCodexBoot。不要使用临时目录，也不要安装到WindowsApps。

首次安装参照README，可用-Preset hanli或-Preset mupeiling。若默认目录已有现有版本，使用不同的InstallDirectory或按素材更新流程操作；安装器会拒绝覆盖已有目录。

打开桌面的HanLi Codex或MuPeiling Codex后，动画和Codex同时启动。窗口默认1600×900、16:9、固定位置和圆角，真实Codex外框在后台匹配开屏区域。Esc跳过；视频缺失或解码失败时尝试官方入口。等待有60秒上限。

已打开Codex时复用其会话；Chromium子进程多于一个不等于多开主实例。任务栏请在验证后手动固定新入口，旧固定项可能缓存路径，本仓库不会替换全部固定项。

## 恢复

未修改原Codex快捷方式，可随时使用原入口。先运行安装目录skin-tools/Restore-Skin.ps1（如果启用过换肤），按提示重启；再运行安装目录Restore-HanLi.ps1。恢复脚本只删除路径和SHA-256都匹配的自建主题快捷方式。变化过的快捷方式会保留。

取消任务栏上的自建固定项，再删除安装目录；不得先删目录后恢复。程序无需卸载或重装。恢复脚本不删除聊天、登录信息或API配置。

现有本机历史安装使用中文恢复CMD，其路径及说明在仓库外的outputs/使用与恢复说明.md；与新安装器创建的英文快捷方式分别管理。
