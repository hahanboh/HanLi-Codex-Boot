# 制作并替换素材包

## 交给助手制作

提供视频文件，并说明角色、希望保留的时间段、文案及是否静音。不确定时间段时可让助手挑选。助手检查画面后完成剪辑、循环衔接、背景截图和启动验证。

素材包包含 `startup.mp4`、`background.jpg`、`launcher-timing.json` 和 `media-manifest.json`。简单开屏只需要其中的MP4；图片及配置供可选换肤或进一步定制使用。

## 自行剪辑

需要Python 3.11+和FFmpeg。例如从视频第14秒开始取14秒片段：

```powershell
python .\tools\create_media.py recording.mp4 --start 14 --duration 14 --loop-start 5 --loop-end 10.5 --output .\private\my-theme
```

--start相对原片；循环参数相对所截片段。输出静音H.264视频，预合成等待段以减少实时跳转。其他选项用 `python tools/create_media.py --help` 查看。输出目录已存在时不会覆盖。

## 替换

先关闭开屏。备份media目录中想替换的示例，把素材包的startup.mp4复制进去并改名为hanli.mp4或mupeiling.mp4，再双击对应CMD。也可以将其命名custom.mp4，双击「使用自己的视频.cmd」。无需改代码或重新编译。

只有需要改变文案、配色时才编辑presets中的对应JSON。运行配置和聊天、登录数据彼此独立，替换视频不修改Codex本身。

自有素材默认放private/，不要把聊天截图、登录数据或未经确认可公开分发的素材提交到仓库。新的公开示例需更新来源说明和公开素材清单。
